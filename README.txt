Contract Distance Sort for Farming Simulator 25

Default key: Right Ctrl + D

The key can be reassigned in Options > Controls under:
Sort active contracts by distance

Press the key to reorder active field-contract blocks in the HUD from the
closest field to the farthest field. Distance is calculated from the current
vehicle position, or from the player position when on foot. After sorting,
each contract title displays its calculated distance in meters or yards,
according to the measurement units selected in the game settings.

The mod changes only the HUD progress-bar order. It does not reorder or alter
the underlying missions and does not write anything to the savegame.
